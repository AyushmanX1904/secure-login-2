How to publish

Follow the instructions in the README to publish this `static-demo` folder to the `gh-pages` branch so you get a shareable URL:

git add static-demo
git commit -m "Add static demo"
# publish using subtree (if supported)
git subtree push --prefix static-demo origin gh-pages

Or use an orphan branch to deploy the files (shown in README).
